# Personal Expense Management System (PEMS)

BCA Project I, Tribhuvan University. Stack: HTML5, CSS3, JavaScript, PHP (PDO), MySQL/MariaDB, XAMPP.

Status: Phase 2 (authentication) complete. The full README is written in Phase 12.

## Quick setup
1. Copy this folder to `C:\xampp\htdocs\PEMS`
2. Start Apache and MySQL in the XAMPP Control Panel
3. phpMyAdmin -> Import -> `database.sql`
4. Open http://localhost/PEMS/
